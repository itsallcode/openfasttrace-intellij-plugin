# OpenFastTrace IntelliJ Plugin 0.10.0, released 2026-08-29

Version 0.10.0 adds specification item status filtering to OpenFastTrace run configurations. Users can include draft, proposed, approved, and rejected items according to their review workflow, while every pre-configured template continues to focus on approved items by default.

## Bundled OpenFastTrace

OpenFastTrace 4.9.0
