# Design

This document describes the architecture of the OpenFastTrace IntelliJ plugin.

User perspective, audience, features, user requirements, and acceptance scenarios are defined in [System Requirements](../system_requirements.md). This design document focuses on architecture, technical decisions, and implementation structure.

The structure follows arc42 with the user-perspective parts reduced to short references instead of duplicated content. The project gratefully uses the arc42 structure created by Gernot Starke and Peter Hruschka.
